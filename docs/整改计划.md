# 汉化工程整改计划

日期：2026-11-20。目标：可审查、可回退、可安装的非官方 Claude Code 简体中文扩展；为 GitHub 开源准备完整源码、测试和发布流程。

交接材料是历史背景；历史的“全量”“实测通过”结论必须重新验证。未经授权不向 GitHub 或 Marketplace 发布，不改动用户会话和凭据。

## 1. 定位与复现（已完成）

- 核对实际安装版本、旧汉化扩展、日志、英文快照及哈希。
- 定位 zod 动态代码生成崩溃的具体误译，建立最小回归用例。
- 检查清单中的侧边栏、视图标题、命令、设置和演练等可见字段。
- 记录备份、恢复、状态判断、安装目录选择及测试工具缺陷。

## 2. 修复与补译（已完成）

- 修复已复现的根因，禁止翻译代码片段、协议值及模块导出名。
- 补齐栏目及其他实际可见文案；让诊断报告反映实际应用范围。
- 修复快照完整性、跨文件写入回退和错误处理，保护英文原件。
- 检测旧汉化扩展冲突，正确定位当前启用的官方扩展。

## 3. 工程与发布整理（已完成）

- 建立无需安装官方扩展即可运行的测试，另设真实 bundle/扩展宿主集成测试。
- 修复 npm 命令、打包白名单、CI 和版本信息；加入开发调试配置。
- 重写安装、恢复、兼容边界及贡献说明，去除虚假覆盖率和占位链接。
- 生成 VSIX，并检查包内无官方源码、缓存、凭据和本机路径。

## 4. 验证与交付（Completed 专项验收完成，完整 GUI 发布验收待完成）

- 运行单元回归、故障注入、幂等与逐字节恢复验证。
- 验证英文/汉化后的真实 Claude Code 激活及 UI；区分桩件与真实宿主证据。
- 在隔离环境安装生成的 VSIX，检查命令及汉化/恢复流程。
- 更新本计划和整改报告，列明结果、证据与尚未验证的边界。

## 初次检查发现的问题（已处理）

- `npm run verify` 指向不存在的 `tools/verify.js`。
- `tools/gap.js --write` 会覆盖已有的同版本人工译文文件。
- 自检会直接修改真实安装，而 CI 没有覆盖核心改写行为。
- 宿主翻译通过缩小范围绕过崩溃，原有审计没有应用相同范围。
- 本机仍安装着另一款汉化扩展，新项目本身尚未安装。
- 快照读取未验证已有 SHA-256；重置可能删除唯一英文备份。
- 多文件写入只有单文件原子替换，没有整批回退。

## 完成记录

- 补齐状态栏筛选中的 Completed，映射为“已完成”；Needs input、Working、Open、Closed、Status、Tabs、Ungrouped 等相关文案均加入回归检查。
- 宿主翻译保留受限 API 范围，避免改写模块导出名、协议值和动态 schema 代码；快照完整性、路径白名单、SHA-256 校验及多文件写入回退已实现。
- 自检使用临时副本；VSIX 打包排除缓存、开发工具、英文 baseline、日志及旧交接文件。未配置虚假的 GitHub 地址。
- 现有记录的验证结果：核心测试 8/8、扩展冒烟 10/10、隔离副本自检 11/11、用户报告文案 8/8、命令标题 31/31；Claude Code 2.1.329 曾在 VS Code 扩展宿主中成功激活并初始化 webview。
