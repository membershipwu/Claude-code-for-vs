| 状态 | 含义 |
|---|---|
| verified | 本机实际运行过表中列出的测试；不代表所有界面经过视觉检查。 |
| untested | 缺少可重放的该版本基线；未覆盖的新文案可能显示英文。 |
| broken | 已确认不兼容，禁止应用。 |

## 审计与升级

使用干净英文扩展副本或校验通过的本地快照运行：

~~~sh
npm run build
npm run verify
node tools/cli.js status
node tools/audit.js
~~~

新增版本前先建立并审阅该版本的英文基线，再检查词库缺口和测试结果；不要把已翻译的活动安装目录当作英文原文。
